# Product-Inventory-Management-System

## About the Project
The Product Inventory Management System is a menu-driven application developed using the C programming language. It helps manage product information, maintain stock records, and perform inventory-related operations efficiently.

The system uses structures and binary file handling to store and manage product records permanently.

## Features

- **Add Product:** Add new products with unique product IDs, names, quantities, and prices.
- **Display Products:** View all available product records.
- **Search Products:** Search products by ID, name, or price range.
- **Sort Products:** Sort products by ID, name, or price.
- **Update Products:** Modify product names, prices, and shop quantities.
- **Delete Products:** Remove product records using product IDs.
- **Stock Transfer:** Transfer stock from the godown to the shop.
- **Purchase Stock:** Add purchased quantities to shop or godown inventory.
- **Low Stock Alert:** Identify products with fewer than 5 units in shop stock.
- **Billing System:** Calculate bills based on product price and quantity.
- **Admin Login:** Access protected revenue and financial information.

## Technologies Used

- Programming Language: C
- File Handling: Binary File Handling
- Compiler: GCC 

## Concepts Implemented

1. Structures
2. User-defined Functions
3. File Handling (`fopen`, `fread`, `fwrite`, `fclose`)
4. CRUD Operations (Create, Read, Update, Delete)
5. Searching Algorithms
6. Sorting Techniques
7. Conditional Statements
8. Loops and Switch Cases
9. String Handling

## How the System Works

The application displays a menu where users can select different inventory management operations. Product records are stored in a binary file, allowing data to remain available after the program is closed.

Users can add, search, update, delete, sort, and manage product stock through the menu-driven interface.
